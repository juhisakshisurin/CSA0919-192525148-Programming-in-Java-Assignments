Benchmark Summary

The benchmark compares the ResultProcessor using fixed thread pools of 1, 2, 4, and 8 threads.

Dataset:
- Expected input files: 10,000
- Successfully processed: 9,688
- Failed/skipped due to missing or invalid data: 312
- Total processed records: 10,000

Benchmark results from the generated test run:
- Pool size 1: 337 ms
- Pool size 2: 264 ms
- Pool size 4: 227 ms
- Pool size 8: 208 ms

Observation:
The measured execution time decreased as the thread-pool size increased in this test environment. The 8-thread configuration was fastest in this run. Actual timings may differ on another computer depending on processor, storage, Java version, and system load.

All pool sizes produced the same success/failure counts. Per-file output CSV files contain the individual processing results.
