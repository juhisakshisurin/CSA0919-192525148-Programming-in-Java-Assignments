## Task Description

Design an inheritance hierarchy for the Campus Smart-Parking System. Identify the superclass and subclasses, explain the type of inheritance, describe inherited and specialized members, demonstrate the use of the `super` keyword and trace the constructor execution order when an ElectricCar object is created.

Additionally, compare inheritance with composition and analyse their time and space complexities.
